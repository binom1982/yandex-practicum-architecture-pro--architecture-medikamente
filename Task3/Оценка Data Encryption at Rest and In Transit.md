# Оценка Data Encryption at Rest and In Transit

## Классификация данных, обоснование необходимости защиты выделенных классов и инструменты защиты данных

| **Данные**                                                                                                                                                                                                                                                                                 | **В чём необходимость защиты**                                                                                                                                                                                                                                                                                                 | **Инструменты защиты**                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Специальные категории ПДн и медицинские данные** <br />``ФИО, диагнозы, результаты анализов, медицинские заключения.``<br />**Критическая чувствительность**       | **Требования:** 152-ФЗ (ст. 10 — специальные категории ПДн), приказы ФСТЭК России.<br />**Риски:** Штрафы Роскомнадзора, репутационные потери, шантаж пациентов, судебные иски.                                   | **At Rest:**• TDE или pgcrypto для PostgreSQL.<br />• BitLocker для файлового сервера (Windows Server).<br />• СКЗИ (КриптоПро) для соответствия высоким уровням защищенности 152-ФЗ.<br />**In Transit:**• TLS 1.2/1.3 для API (мобильное приложение, интеграция с лабораторией).<br />• mTLS для трафика между микросервисами в Kubernetes. |
| **Платежные и финансовые данные** <br />``Реквизиты банковских карт, история транзакций, данные о зарплатах.``<br />**Высокая чувствительность**                                  | **Требования:** PCI DSS (если принимаются карты), банковская тайна, защита коммерческой тайны. <br />**Риски:** Финансовое мошенничество, штрафы от платежных систем, уголовная ответственность. | **At Rest:**• Токенизация (хранение токенов вместо реальных данных карт).<br />• Шифрование файловых баз 1С или переход на СУБД с шифрованием.<br />**In Transit:** <br />• TLS 1.3 с строгими cipher suites для обмена с банками и ФНС.<br />• VPN/IPsec для выделенных каналов связи.                                                        |
| **Учетные данные и средства аутентификации** <br />``Логины, хэши паролей, токены сессий, SSL-сертификаты, ключи шифрования.``<br />**Критическая чувствительность** | **Требования:** Защита средств аутентификации, криптографическая защита по стандартам ФСТЭК. <br />**Риски:** Полный захват контроля над системами, компрометация всех данных компании.        | **At Rest:**• Хеширование паролей (Argon2, bcrypt) с уникальной "солью".<br />• HashiCorp Vault для хранения мастер-ключей, сертификатов и токенов API.<br />**In Transit**:<br />• Передача JWT только по HTTPS с флагами Secure и HttpOnly.<br />• Строгая валидация сертификатов.                                                                                    |
| **Данные ТМЦ и операционные данные** <br />``Остатки на складе, закупочные цены, внутренние регламенты.``<br />**Средняя чувствительность**                                            | **Требования:** Защита коммерческой тайны, внутреннее пользование. <br />**Риски:** Промышленный шпионаж, нарушение непрерывности бизнеса, утечка конкурентной информации.                               | **At Rest:**<br />• Разграничение прав NTFS + аудит доступа.<br />**In Transit:** <br />• gRPC over TLS или HTTPS для внутренних коммуникаций (замена небезопасного OLE в 1С).                                                                                                                                                                                                                                                |

## Средства автоматизированного контроля данных

| **Категория контроля**                              | **Инструмент / Подход**                                                                                                                 | **Что контролирует**                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Аудит доступа к данным                                  | Встроенный аудит PostgreSQL (`pgaudit`), <br />аудит файлового сервера Windows Server, <br />логи API-шлюзов  | Кто, когда и к каким ПДн/медкартам обращался.<br />Фиксация попыток несанкционированного доступа.                                                                                             |
| SIEM-система (сбор и корреляция событий)      | Elastic SIEM / Kibana (входит в целевой стек компании)<br /> или отечественный аналог (Wazuh, MaxPatrol SIEM) | Агрегация логов со всех систем, выявление аномалий (например, массовая выгрузка данных), <br />алертинг в случае инцидентов.                                              |
| DLP-система (предотвращение утечек)             | Информация / Solar doZor / SearchInform (сертифицированные ФСТЭК решения)                                              | Контроль каналов передачи ПДн (email, мессенджеры, съёмные носители, печать). <br />Блокировка попыток выгрузить медицинские карты наружу.                        |
| Контроль целостности (FIM — File Integrity Monitoring) | OSSEC, Wazuh FIM, Tripwire                                                                                                                                    | Отслеживание изменений в критичных файлах: конфигурации БД, хранилища ключей, медицинские записи. <br />Алерт при несанкционированной модификации. |
| Мониторинг аномалий поведения (UEBA)            | Elastic ML, VictoriaMetrics + правила корреляции (входит в стек техдира)                                                   | Выявление нетипичных действий: врач скачивает карты пациентов, <br />которых не лечил; доступ в нерабочее время и т.д.                                                          |
| Сканеры уязвимостей и конфигураций          | OpenVAS, MaxPatrol VM, Kubernetes Policy Controller (OPA/Gatekeeper)                                                                                          | Регулярная проверка настроек TLS, <br />политик безопасности в Kubernetes, <br />отсутствие уязвимостей в образах контейнеров.                                                        |
| Мониторинг состояния шифрования               | Prometheus + VictoriaMetrics + собственные метрики                                                                                          | Контроль того, что все каналы работают по TLS 1.2+, <br />все диски зашифрованы, <br />сертификаты не просрочены.                                                                               |

## Реестр программных и аппаратных средств защиты данных

| **№** | **Средство защиты**                                                     | **Тип**                          | **Назначение**                                                                                          | **Обоснование выбора**                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1            | BitLocker                                                                                   | ПО (ОС)                               | Шифрование дисков файловых серверов и рабочих станций                    | Встроено в Windows Server 2022, защищает от физической кражи, не требует лицензий.                                |
| 2            | PostgreSQL TDE / `pgcrypto`                                                              | ПО (СУБД)                           | Шифрование БД с ПДн и медкартами на уровне хранилища                        | Соответствует целевому стеку техдира.` pgcrypto`— для выборочного шифрования полей.                 |
| 3            | КриптоПро CSP                                                                      | ПО (СКЗИ)                           | Криптографическая защита по требованиям 152-ФЗ и ФСТЭК                      | Обязательна для работы со специальными категориями ПДн в РФ. Сертифицированное средство. |
| 4            | HashiCorp Vault                                                                             | ПО                                      | Хранилище секретов (ключи, сертификаты, токены)                                  | Централизованное управление ключами шифрования. Интегрируется с Kubernetes.                                 |
| 5            | TLS 1.2/1.3 + mTLS                                                                          | Протокол / ПО                   | Шифрование трафика In Transit (API, мобильное приложение, микросервисы) | Промышленный стандарт. mTLS — для взаимной аутентификации сервисов в K8s.                                     |
| 6            | Elastic SIEM / Kibana                                                                       | ПО                                      | Сбор, анализ и корреляция логов безопасности                                      | Входит в целевой стек компании. Позволяет строить аудит и выявлять инциденты.                       |
| 7            | Wazuh / MaxPatrol SIEM                                                                      | ПО                                      | DLP + FIM + SIEM (отечественные аналоги)                                                            | Соответствие требованиям импортозамещения и 152-ФЗ. Контроль целостности файлов.                  |
| 8            | Active Directory + RBAC                                                                     | ПО                                      | Управление доступом и аутентификация                                                   | Уже развёрнуто. Основа для ролевой модели доступа к ПДн.                                                               |
| 9            | Сертифицированный межсетевой экран (UserGate / Check Point) | Аппаратно-программный | Сегментация сети, контроль сетевых потоков                                         | Обязателен для изоляции контура обработки ПДн по требованиям ФСТЭК.                                        |
| 10           | Сервер резервного копирования (Veeam / Commvault)                | ПО + оборудование           | Шифрованные бэкапы с контролем целостности                                        | Защита от потери данных (Ransomware, сбои). Бэкапы должны храниться зашифрованными.                       |
| 11           | Prometheus + VictoriaMetrics                                                                | ПО                                      | Мониторинг состояния систем защиты                                                       | Входит в стек техдира. Контроль работоспособности TLS, дисков, сервисов шифрования.               |
